# Memory Trainer Quest

A professional desktop application built with Python and CustomTkinter designed to help users train and improve their memory using various mnemonic techniques.

## Features

- **Multiple Game Modes**: Practice with Numbers, Phone Numbers, Alphanumeric strings, Words, and Sequences.
- **Practice Mode & Auto Coach**: Learn techniques like Chunking, Story Linking, and the Memory Palace with real-time tips.
- **Authentication System**: Create an account, login, and save your progress. Supports multiple users on the same machine.
- **Daily Streak**: Keep track of your daily practice consistency.
- **Daily Quest**: Complete daily challenges to boost your skills.
- **Visual Aids**: Colorful chunking and high-contrast text for better memorization.
- **Customizable Difficulty**: Adjust display and recall times to match your skill level.

## Installation

Ensure you have Python installed. You can install the dependencies (mainly `customtkinter`) using `pip` or `uv`.

### Using pip
```bash
pip install customtkinter
```

### Using uv
```bash
uv pip install customtkinter
```

## How to Run

Navigate to the project directory and run:

```bash
python memory_app.py
```
